SELENE — Storefront Preview

START
Serve this folder with any static web host, then open index.html through that host. Serving locally is recommended because browser storage can be restricted when a page is opened directly from disk.

PAGES
- Home and the mixed Shop All collection
- Bags and Tops collections
- Product detail pages for all 21 listed pieces
- Lookbook, About, Contact, FAQs and Sitemap
- Shopping bag, account preview, checkout preview and local order history

PREVIEW BEHAVIOR
The bag, preview profile and preview order history are stored in the current browser. Profile data contains only a name and email. No password is requested or stored. Checkout saves a sample order on this device; it does not process payment, send an order to SELENE, or arrange delivery. Do not enter sensitive information.

PRODUCTION NEXT STEPS
Before accepting real orders, connect the catalog and stock to a trusted backend, implement secure customer accounts, add a payment provider and order fulfilment, and publish accurate shipping, returns and privacy information.

The storefront uses local system fonts and the supplied images, so it has no required third-party font or script services.
